🎮 GearsHouse – Gaming Gear E-commerce Platform

GearsHouse is a modern e-commerce solution for gaming gear built with ASP.NET Core MVC. The project emphasizes a seamless User Experience (UX) and a highly responsive User Interface (UI).



✨ Front-end \& UX Highlights

Responsive Design: Fully optimized for Mobile, Tablet, and Desktop.



Interactive UI: Smart product filtering, real-time search, and AJAX-powered shopping cart.



Modern Components: Utilizing Razor Partial Views for clean, reusable UI components.



Data Visualization: Admin dashboard featuring intuitive charts for revenue tracking.



Real-time Support: Integrated live chat widget for instant customer assistance.



🚀 Key Features

Storefront: Product browsing by Brand/Category, detailed reviews, and promotions.



Checkout Flow: Secure shopping cart with VNPay \& MoMo payment integration.



Order Tracking: Real-time order status updates and automated PDF Invoice generation.



Admin Panel: Full CRUD management for products, orders, coupons, and users.



Security: Robust authentication and authorization using ASP.NET Identity.



🛠 Tech Stack

Core: ASP.NET Core MVC (.NET 8/9)



Frontend: HTML5, CSS3, JavaScript, Bootstrap, Razor Views.



Database: SQL Server \& Entity Framework Core.



Integrations: VNPay/MoMo APIs, SMTP Email, PDF Generator.



⚙️ Quick Start

Clone: git clone https://github.com/MinhLoc0212/ecommerce-shopping-online-project.git



Config: Update appsettings.json with your ConnectionString and API Keys.



Database: Run dotnet ef database update.



Run: Execute dotnet run or start via Visual Studio.
